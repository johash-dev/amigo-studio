# Handoff & Context

Capture only information needed to continue safely.

Handoff files for **product** work live in the project (`docs/` or an existing `handoff/` folder). Do not paste novels into studio state.

```text
Task:
Current state:
Completed:
Files changed:
Decisions:
Requirements:
Validation:
Failures:
Open questions:
Known risks:
Next exact step:
Commands:
```

Do not copy the entire conversation. Do not hide uncertainty. Do not state assumptions as facts. Prefer paths and IDs over pasted specs.
